# Programación entera en R

## Descripción

Este proyecto desarrolla la resolución de problemas de programación entera mediante el lenguaje R y la librería `lpSolve`.

El programa permite formular problemas de optimización a partir de variables de decisión, una función objetivo y un conjunto de restricciones. Posteriormente, utiliza un solver para obtener la solución óptima del modelo, respetando las condiciones establecidas.

El proyecto incluye la aplicación de estos métodos a problemas de optimización relacionados con la producción y comercialización de productos.

## Tecnologías utilizadas

- **R:** lenguaje utilizado para implementar el programa.
- **lpSolve:** librería empleada para formular y resolver problemas de programación lineal y entera.

## Instalación

Es necesario tener R instalado y disponer de la librería `lpSolve`.

Para instalarla:

```r
install.packages("lpSolve")
```

## Uso

1. Abrir el proyecto en RStudio.
2. Instalar las dependencias necesarias.
3. Ejecutar el script correspondiente.
4. Consultar la solución obtenida por el optimizador.

## Objetivo

El propósito del proyecto es aplicar técnicas de investigación operativa y optimización matemática mediante herramientas computacionales, facilitando la resolución de problemas de programación entera.
